## 📱 Опис на апликацијата

**Bitola City Explorer** е iOS апликација изработена во **Swift / SwiftUI**, чија цел е да им помогне на корисниците полесно да откриваат туристички локации, ресторани, културни објекти, кафулиња, продавници и други интересни места во Битола.

Апликацијата овозможува корисникот да ги разгледува местата, да ги прикажува на мапа, да ја користи својата моментална локација, да прегледува детални информации за секое место и да ги зачувува омилените локации.

Дополнително, апликацијата користи камера, FaceID, локални mock нотификации, надворешен API сервис за временска прогноза и локално зачувување на кориснички податоци.

Главната цел на апликацијата е корисникот брзо да најде интересни места во близина, да ги види на мапа, да зачува омилени локации и да добива известувања за препорачани места.

Апликацијата ги содржи следните функционалности:

* 🗺️ Приказ на мапа со локации во Битола
* 📍 Користење на моменталната GPS локација на корисникот
* ℹ️ Приказ на детални информации за избрана локација
* ❤️ Зачувување на омилени места со SwiftData

* 🔔 Mock локални нотификации
* 📷 Користење на камера за фотографирање на посетено место
* 🔐 FaceID автентикација за пристап до омилени места
* 🌤️ Надворешен API за временска прогноза
* 🎨 Custom SwiftUI компонента со сопствен изглед и анимација
* 📦 3rd party библиотека
* 📱 Повеќе различни views/screens

# 📱 Екрани во апликацијата

## 1. Splash Screen

Почетен екран кој се прикажува при стартување на апликацијата.

Содржи:

* лого на апликацијата
* име **BITOLA CITY EXPLORER**
* custom анимација
* анимирана икона
* gradient позадина

По краткото прикажување, корисникот продолжува кон главниот екран.

---

## 2. Home Screen

Главниот екран на апликацијата.

На него се прикажува листа од препорачани и интересни места во Битола.

Секое место е прикажано преку custom компонента која содржи:

* слика
* име на локацијата
* категорија
* краток опис
* оддалеченост од корисникот
* копче за додавање во омилени

Со притискање на картичката корисникот може да отвори детални информации за местото.

---

## 3. Map Screen

Екран со интерактивна мапа на Битола.

На мапата се прикажуваат:

* моменталната локација на корисникот
* маркери за достапните места
* име на локацијата
* можност за избирање локација
* копче за центрирање на мапата кон корисникот

Со притискање на одреден marker може да се отвори деталниот екран за избраното место.

---

## 4. Place Details Screen

Екран со детални информации за избраната локација.

Содржи:

* слика
* име
* категорија
* адреса
* оддалеченост
* опис
* моментална временска прогноза
* копче за додавање/отстранување од омилени
* копче за отворање на камера
* копче за креирање mock нотификација

Временската прогноза се презема преку надворешен API според координатите на избраното место.

---

## 5. Favorites Screen

Екран на кој се прикажуваат сите места кои корисникот ги има зачувано како омилени.

Податоците се зачувуваат локално со **SwiftData**.

За дополнителна безбедност, пристапот до омилените места користи **FaceID автентикација**.

---

## 6. Camera Screen

Екран кој овозможува користење на камерата на iPhone.

Корисникот може да фотографира место кое го посетува директно преку апликацијата.

Со ова се исполнува условот апликацијата да користи камера како еден од хардверските ресурси на уредот.

---

## 7. Settings Screen

Екран за кориснички подесувања.

Корисникот може да менува и зачувува различни параметри, како:

* dark mode
* дозвола за нотификации
* кориснички преференци

Подесувањата се зачувуваат локално со **UserDefaults**.

# 🗺️ Maps и Location Services

Апликацијата користи мапа за прикажување на достапните места во Битола.

За секое место се зачувуваат координати:

```text
latitude
longitude
```

Локацискиот сервис овозможува добивање на моменталната GPS локација на корисникот.

Врз основа на неа апликацијата може да ја пресмета оддалеченоста помеѓу корисникот и избраното место.

---

# 🔔 Mock Notifications

Апликацијата поддржува локални mock нотификации.

Корисникот може од деталниот екран на одредена локација да активира нотификација која ќе се прикаже по краток временски период.

Пример:

```text
Bitola City Explorer

Не заборавај да го посетиш избраното место!
```

За управување со нотификациите се користи:

```text
NotificationService
```

---

# 📷 Camera

Апликацијата овозможува пристап до камерата на iPhone.

Камерата може да се отвори од деталниот екран за одредено место.

Корисникот може да фотографира локација која ја посетува.

За управување со камерата се користи:

```text
CameraService
```

---

# 🔐 FaceID

FaceID се користи како дополнителен сензор и безбедносна функционалност.

При пристап до омилените места, корисникот може да биде автентициран преку FaceID.

За автентикацијата се користи:

```text
AuthService
```

---

# 🌤️ Надворешен API

Апликацијата користи надворешен API сервис за добивање податоци за временска прогноза.

Кога корисникот ќе отвори детал за одредено место, апликацијата ги користи:

```text
latitude
longitude
```

на избраната локација и презема информации за:

* моментална температура
* временски услови
* дополнителни информации за времето

Во проектната спецификација како пример е предвиден:

```text
OpenWeather API
```

За комуникација со API сервисот се користи:

```text
WeatherAPIService
```

# 📦 3rd Party Library

Во апликацијата се користи **Kingfisher**.

Kingfisher се користи за преземање и кеширање на слики од интернет.

Главната примена е:

* преземање слики за туристички места
* автоматско кеширање
* побрзо повторно вчитување на сликите

# 🎨 Custom View компонента

Апликацијата содржи сопствена SwiftUI компонента:

```swift
AnimatedPlaceCard
```

Компонентата се користи за прикажување на местата на Home Screen.

Картичката содржи:

* слика
* име
* категорија
* опис
* оддалеченост
* favorite копче

Custom компонентата има сопствен изглед и анимации:

* rounded corners
* shadow
* scale effect
* opacity animation
* animation при притискање

Пример:

```swift
.scaleEffect(isPressed ? 0.97 : 1)
.opacity(isPressed ? 0.88 : 1)
.animation(
    .spring(
        response: 0.28,
        dampingFraction: 0.68
    ),
    value: isPressed
)
```

# 💾 Локално зачувување на податоци

Апликацијата користи два начина за локално зачувување:

## SwiftData

SwiftData се користи за зачувување на омилените места.

За секое омилено место може да се зачуваат:

```text
id
name
description
latitude
longitude
imageUrl
```

Со ова омилените места остануваат зачувани и после повторно стартување на апликацијата.

---

## UserDefaults

UserDefaults се користи за зачувување на корисничките подесувања.

Пример:

```text
Dark Mode
Notifications Enabled
User Preferences
```

# 🛠️ Сервиси

Апликацијата е организирана со повеќе сервиси, при што секој сервис има посебна одговорност.

### LocationService

Сервис за добивање на моменталната GPS локација на корисникот.

```text
LocationService
```

### MapService

Сервис за работа со мапата, координатите и локациите.

```text
MapService
```

### NotificationService

Сервис за испраќање на локални mock нотификации.

```text
NotificationService
```

### CameraService

Сервис за пристап и работа со камерата.

```text
CameraService
```

### AuthService

Сервис за FaceID автентикација.

```text
AuthService
```

### WeatherAPIService

Сервис за комуникација со надворешниот API за временска прогноза.

```text
WeatherAPIService
```

### StorageService

Сервис за локално зачувување и управување со податоците преку SwiftData и UserDefaults.

```text
StorageService
```
